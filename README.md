# Terminal RPG

A persistent, turn-based text-driven Role-Playing Game built in Java using Object-Oriented Programming (OOP) design patterns.

##  Key Features
* **Hero Classes:** Choose between `Warrior` and `Mage` classes, each with distinct stats and attributes.
* **Turn-Based Combat:** Engage enemies in room-by-room combat encounters.
* **Inventory & Items:** Pick up and use consumable health potions during battles.
* **State Persistence:** Save game progress to file (`savegame.txt`) and load player stats, current room index, and inventory persistence across sessions.

##  Concepts & Technologies
* **Language:** Java (JDK 17+)
* **Architecture:** Object-Oriented Programming (Polymorphism, Inheritance, Encapsulation)
* **Storage:** Custom File I/O service (`Scanner` / `PrintWriter`) for state persistence
* **Version Control:** Git & GitHub
